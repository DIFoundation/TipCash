FEATURE OVERVIEW
───────────────────────────────────────────────────────────────────────────────
Added QR code generation and display capabilities to TipCash, allowing users to
easily share their Zcash addresses and receive links via scannable QR codes.

                              USER INTERACTION FLOW
════════════════════════════════════════════════════════════════════════════════

SCENARIO 1: Share Zcash Address
  User → Visit /receive
       → See Zcash address with QR code
       → Can:
          • Copy address to clipboard
          • Download QR code as PNG
          • Share QR code with friends

SCENARIO 2: Share Receive Link
  User → Visit /receive
       → See shareable link with QR code
       → Can:
          • Copy link to clipboard
          • Download QR code
          • Share on social media

SCENARIO 3: Manage Receive Links
  User → Visit /receive-links
       → Create new link (regular or anonymous)
       → Each link shows in list
       → Can:
          • Click expand arrow to show QR code
          • Download QR code for each link
          • Copy link with one click
          • See link metadata (created date, expiration)

                            TECHNICAL ARCHITECTURE
════════════════════════════════════════════════════════════════════════════════

COMPONENT STRUCTURE

┌─ QRCodeDisplay Component
│  ├── Props
│  │   ├── value: string (required) - Data to encode
│  │   ├── label?: string - Description
│  │   ├── size?: number - Pixel size (default: 256)
│  │   ├── level?: 'L'|'M'|'Q'|'H' - Error correction
│  │   ├── includeMargin?: boolean
│  │   └── showDownload?: boolean
│  │
│  ├── State
│  │   └── qrRef - Reference to container for canvas access
│  │
│  ├── Methods
│  │   └── downloadQRCode() - Export as PNG
│  │
│  └── UI Layout
│      ├── White background container
│      ├── QR code canvas
│      ├── Optional label text
│      └── Optional download button
